# StudyBridge MVP
Real MVP: mobile dashboard, PDF upload, AI tutor grounded on uploaded PDF, vocabulary generation, quiz generation.

## Run
Node.js 20.9+ required.
1. npm install
2. copy .env.example to .env.local
3. add OPENAI_API_KEY
4. npm run dev
5. open http://localhost:3000

Never expose the API key in client code.
